🪞 EasyWear Smart Mirror & Smart Closet
EasyWear is an interactive, web-based Smart Mirror application designed for modern personal fashion management. Built with React, Tailwind CSS, and WebKit-optimized Glassmorphism UI, EasyWear turns any screen into a smart wardrobe assistant that helps users pick daily outfits based on weather conditions, track RFID wardrobe inventory, and manage laundry cycles.

✨ Key Features
🪞 Smart Mirror Glass UI: Glassmorphism dashboard featuring ambient reflections, wake-up screens, dynamic clocks, and full Arabic (RTL) localization.

👕 Interactive Outfit Styling: Two-step styling workflow allowing users to choose an outfit category (Casual, Formal, or Sportswear) and individually customize Tops, Bottoms, and Shoes.

⛅ Dynamic Weather Widget: Live temperature display with interactive weather presets (Sunny, Mild Breeze, Cool & Rainy) that adapt clothing recommendations dynamically.

📊 Wardrobe RFID & Laundry Tracker: Real-time inventory statistics displaying available clothing items versus items currently in the smart laundry cycle, complete with single-item or bulk return toggles.

🏷️ Google Drive Image Integration: Dynamically populates wardrobe gallery slots using Google Drive File IDs with cross-origin image fallback handling.

📱 Full Mobile & iPad Optimization: Touch-optimized layout supporting both portrait and landscape rotations with -webkit-overflow-scrolling: touch for smooth scrolling.

🌐 Cross-Browser & Safari Compatible: Configured for WebKit support (-webkit-backdrop-filter) and standalone Babel compilation without browser CORS issues.

💼 Business Pitch Modal: Built-in entrepreneurship project documentation covering Vision, Mission, Value Proposition, and Team roles.
